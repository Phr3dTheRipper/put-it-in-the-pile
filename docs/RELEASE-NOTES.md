## The world had enough. We made one anyway.

A native Windows Codex usage meter with real quota data, an always-on-top toggle, a compact strip, and a button that puts another usage meter in the pile.

### Download

Download **PutItInThePile-Windows.zip**, extract it to a writable folder, and run **PutItInThePile.exe**. `SHA256SUMS.txt` contains the ZIP's SHA-256 checksum.

**Windows 10/11 with .NET Framework 4.8.** Live usage requires an existing ChatGPT-backed Codex sign-in and `codex.exe`. The three-dot menu offers labeled demo data without signing in.

The executable is **unsigned** and may trigger Windows reputation warnings or be blocked by managed policies. Verify the source and checksum before running it.

Press **Esc** for compact mode. Click **PUT IT IN THE PILE** for an unprecedented increase in the number of usage meters.

Source and build scripts are included. Unofficial parody, unaffiliated with OpenAI. MIT licensed.
